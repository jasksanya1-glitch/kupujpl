Jak włączyć powiadomienia push (instrukcja)
  1. Zaloguj się i kliknij Włącz powiadomienia push powyżej.
  2. Przeglądarka zapyta o zgodę — wybierz Zezwól.
  3. Chrome / Edge (Android, PC): działa od razu; opcjonalnie „Zainstaluj aplikację” z menu przeglądarki.
  4. iPhone (Safari): Udostępnij → Dodaj do ekranu początkowego, potem otwórz ikonę KupujPL i włącz push w panelu.
  5. Włącz Alert cenowy przy grze na liście poniżej — push idzie tylko dla gier z alertem.
  6. Jeśli nie widzisz pytania o zgodę: ustawienia przeglądarki → Powiadomienia → zezwól dla kupujpl.pl.

Import z Steam Wishlist

Jak udostępnić wishlistę Steam (instrukcja)
  1. Otwórz klienta Steam → kliknij swój profil (awatar u góry).
  2. Wybierz Edytuj profil → zakładka Prywatność.
  3. Ustaw Mój profil: Publiczny.
  4. Ustaw Szczegóły gry (Game details) na Publiczne — wtedy wishlista też jest widoczna.
  5. Opcjonalnie: w przeglądarce wejdź na steamcommunity.com/profiles/TWOJE_ID i sprawdź, czy widać zakładkę Lista życzeń.
  6. Skopiuj link do profilu (np. https://steamcommunity.com/profiles/7656119…) albo nick z /id/nick, albo 17-cyfrowy SteamID64.

Nie podajemy hasła do Steam — czytamy tylko publiczną listę życzeń.
